# Exercise 01: Basic Git Operations

## Objective
Learn how to track files, stage changes, create commits, and view Git history.

## Steps Performed
1. Created a sample text file.
2. Checked the repository status.
3. Staged the file using `git add`.
4. Committed the file using `git commit`.
5. Viewed the commit history using `git log`.

## Commands
```bash
git status
git add sample.txt
git commit -m "Add first practice file"
git log --oneline
```

## Result
The sample file was tracked and committed successfully.
