## Instructions to Compile and Run

Make sure GCC is installed.

Open Terminal and navigate to the required exercise folder.

Compile the program:
```bash
gcc main.c -o program
```

Run the program:
```bash
./program
```

If the program reads input from the keyboard, enter the sample input when prompted.

If it reads from a file, use:
```bash
./program < input.txt
```
